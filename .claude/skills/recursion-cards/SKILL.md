# 재귀 호출 카드

재귀 함수를 실제로 실행한 기록으로, 호출 하나를 카드 하나로 그린다.
순차 실행에 익숙한 학생이 "실행 도중 새 공간이 생기고 그 안에서 같은 규칙을 반복한다"는 것을 코드 줄 단위로 보게 하는 것이 목적이다.

## 생성 방법

같은 폴더의 `recur_cards.py`를 쓴다. 표현 규칙은 전부 이 스크립트에 구현되어 있다. 규칙을 바꾸면 스크립트와 이 문서를 같이 고친다.

- 내장 예제(교과서 07, factorial(5), fib(4)): `python -X utf8 recur_cards.py OUT.html [이름 ...]`
- 임의의 함수: `python -X utf8 recur_cards.py OUT.html --src SRC.py "첫 호출식"` (`--src` 묶음을 여러 개 주면 한 페이지에 차례로 그린다)
  - SRC.py에는 함수 정의와 함수가 쓰는 전역 변수를 넣는다. 함수 본문은 4칸 들여쓰기여야 한다.
- 출력은 외부 파일 없이 열리는 HTML 한 장이다. 결과는 크롬으로 열어 사용자에게 보여 준다.
- 다른 학습자료 HTML 안에 넣을 때: 빌더에서 이 폴더를 sys.path에 넣고 `recur_cards`를 import한다. `figure(src, call)`로 접기/펼치기 그림 HTML 조각을 받는다(배치만 필요하면 `build(src, call, folded=False)`, 그리기는 `render(d, title=False)`). CSS는 `recur_cards.CSS`에서 body, h2 규칙을 뺀 나머지를 쓴다. (13-2 복습자료가 이 방식)
- 카드용 입력은 작게 잡는다(호출 10개 안팎). 본문 코드와 같은 함수를 작은 입력으로 따로 실행해 그리고, 그림 위 한 줄에 입력을 적는다.

## 확정된 표현 규칙

### 전체
- 정적 그림이다. 단계 재생, 애니메이션, 재생 버튼을 넣지 않는다. 실행이 끝난 뒤의 모든 카드가 한 번에 보인다.
- 카드끼리 화살표로 잇지 않는다. 위치와 카드 길이로 관계를 보인다.
- 세로(위 -> 아래)는 시간, 가로(왼 -> 오)는 콜 스택 깊이다.

### 카드 위치와 길이
- 자식 카드는 호출한 줄 바로 아래에서 시작한다. 왼쪽 끝은 그 줄의 호출식(예: `f(`, `factorial(`)이 시작하는 글자 위치에 맞춘다.
- 부모 카드는 자식 호출이 모두 끝날 때까지 아래로 늘어난다. 자식이 끝난 뒤 부모의 다음 줄은 자식 카드 아래에 이어진다.
- 한 줄에서 두 번 이상 호출하면(`fib(n - 1) + fib(n - 2)`) 두 번째 카드는 첫 번째 카드가 끝난 아래, 첫 번째 카드와 같은 가로 위치(같은 깊이)에 놓는다. 두 번째 호출식 위치에 맞추면 하위 호출처럼 보이므로 그렇게 하지 않는다.
- 자식 카드가 부모 카드 위에 겹쳐 놓인다. 나중 호출일수록 위에 그린다.

### 카드 내용
- 헤더: 호출식(`factorial(5)`, `f(0, 0, 1)`)과, 오른쪽에 호출 직후의 지역변수(`k = 0, s = 0, j = 1`).
- 본문: 실제로 실행된 줄만, 실행된 순서대로 쓴다. 실행되지 않은 줄은 쓰지 않는다. 들여쓰기는 원본 코드를 따른다.
- 반복문 때문에 같은 줄이 여러 번 실행되면 그 횟수만큼 반복해서 쓴다(예: `for ...:` / `f(i, ...)` 두 줄이 반복). 이것은 의도된 모습이다.
- 반복이 끝나는 마지막 반복문 머리 줄 아래에는 한 단계 들여서 회색 주석으로 이유를 쓴다. 그다음 줄은 원래 들여쓰기로 돌아간다.
  - for: `# range(k+1, len(A))에 남은 i 값이 없어 반복 끝` (반복 대상과 반복 변수를 원본 코드에서 그대로 가져온다)
  - while: `# 조건 이(가) 거짓이라 반복 끝`
  - 한 번도 돌지 않은 반복도 같은 주석이 붙는다.
- if 조건이 거짓이라 본문을 건너뛰면, 그 if 줄 아래에 한 단계 들여서 회색 주석 `# 조건식 : 거짓이라 건너뜀`을 쓴다(예: `# i in path : 거짓이라 건너뜀`). 이것이 없으면 if 아래 블록이 생략된 것처럼 보인다.
  - while은 `# 조건식 : 거짓이라 반복 끝`.
  - 판정 방법은 반복 끝과 같다: 머리 줄 다음에 같은 호출에서 실행된 줄이 본문 밖이면 건너뛴 것이다. 머리 줄과 본문이 한 줄인 경우(`if x: return`)는 판정하지 않는다.
- `continue` 다음에 반복문 머리 줄이 바로 오는 것은 실제 실행 순서 그대로이므로 따로 표시하지 않는다.

### 반환 표시 (git diff 형식)
- 재귀 호출이 들어 있는 return 문: 카드 맨 아래에 두 줄을 붙인다.
  - 빨간 줄(`-`): 실행된 return 문을 그대로 쓰고, 재귀 호출 부분에 취소선을 긋는다. 예: `- return n * factorial(n - 1)`에서 `factorial(n - 1)`에 취소선.
  - 초록 줄(`+`): 호출 부분만 돌려받은 값으로 바꾸고 나머지 식은 그대로 둔다. 계산 결과는 주석으로 붙인다. 예: `+ return n * 2   # 6`, `+ return 1 + 0   # 1`.
  - 결과를 최종값 하나(`return 6`)로 뭉뚱그리지 않는다.
- 호출이 없는 return 문(`return 1`, `return n`, 빈 `return`): 다시 쓰지 않는다. 실행된 그 줄을 초록으로 칠하고 끝에 `   # 값`만 붙인다. 예: `return n   # 1`, `return   # None`.
- return 문 없이 함수 끝에 닿은 경우: 맨 아래에 초록 `return   # None` 줄을 붙인다.

### 접기/펼치기
- 그림은 처음에 접힌 상태로 나온다. 첫 호출(가장 바깥 카드)은 코드 줄까지 펼쳐 둔다. 나머지 모든 카드도 중첩 구조 그대로 나오지만 코드 줄은 숨기고 헤더(호출식, 지역변수)만 보인다. 자식 카드는 부모 헤더 바로 아래에 한 단계 들여 놓는다.
  - 안쪽 호출을 아예 감추는 것이 아니다. 카드는 다 보이고 세부 코드만 숨긴다.
- 그림을 누르면 모든 카드가 펼쳐지고, 다시 누르면 처음 상태로 접힌다.
- 접힌 그림과 펼친 그림은 생성 때 두 번 배치해 함께 싣고, 누를 때 둘 중 하나만 보인다(`figure(src, call)`).

### 형식
- 장식을 넣지 않는다. 글꼴은 고정폭, 색은 빨강/초록(diff), 회색(반복 끝 주석)만 쓴다.
- 그림 안에서 표시 방식을 설명하는 문장(범례 등)을 넣지 않는다.

## 알려진 한계

- 한 줄에 호출이 여러 개인데 일부만 실행되는 식(`f(a) or f(b)` 등)은 값 대입을 하지 못하고 원래 문장에 `# 결과`만 붙인다.
- 전역 변수에 결과를 쌓는 함수(교과서 07의 `ans`)는 모든 카드가 `return   # None`으로 끝나고, 전역 변수가 바뀌는 모습은 그림에 나오지 않는다.
- 호출 수가 많으면 세로로 길어진다(교과서 07: 호출 93개, 약 15,700px).
- 호출 하나의 실행 줄이 매우 많으면(긴 반복) 카드도 그만큼 길어진다.

## 검증

생성 후 playwright로 전체 페이지 스크린샷을 찍어 다음을 확인한다.
- 카드가 호출식 위치에 맞춰 시작하는지, 형제 호출이 같은 가로 위치인지
- 초록 줄의 대입값이 실제 반환값과 맞는지
- 글자가 카드 밖으로 넘치지 않는지
