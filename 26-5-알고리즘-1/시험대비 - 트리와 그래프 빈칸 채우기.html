시험대비 - 트리와 그래프 빈칸 채우기

빈칸 채우기는 네모 칸에 들어갈 코드를 쓴다. 코드 작성은 네모 칸에 여러 줄의 코드를 쓴다. 리스트로 저장한 트리는 루트가 인덱스 1이고 0은 빈 칸이다.

트리

1 빈칸 채우기
리스트로 저장한 이진 트리에서 인덱스 idx 노드의 부모, 왼쪽 자식, 오른쪽 자식을 출력하는 코드이다.
# 리스트로 이진 트리 표현 (인덱스 0은 비워둠) tree = [0, 10, 20, 30, 40, 50, 60, 70] def find_family(idx): print(f"현재 노드: {tree[idx]}") # 1. 부모 노드 구하기 parent_idx = 가 parent_val = tree[parent_idx] if parent_idx >= 1 else "없음" # 2. 왼쪽 자식 구하기 left_idx = 나 left_val = tree[left_idx] if 다 and tree[left_idx] != 0 else "없음" # 3. 오른쪽 자식 구하기 right_idx = 라 right_val = tree[right_idx] if right_idx < len(tree) and tree[right_idx] != 0 else "없음" print(f"부모 노드: {parent_val}") print(f"왼쪽 자식: {left_val}") print(f"오른쪽 자식: {right_val}") find_family(2)
2 코드 작성
1번의 find_family에서 parent_val, left_val, right_val을 구하는 부분을 작성하시오. 부모나 자식이 없으면 "없음"으로 한다.
tree = [0, 10, 20, 30, 40, 50, 60, 70] def find_family(idx): print(f"현재 노드: {tree[idx]}") print(f"부모 노드: {parent_val}") print(f"왼쪽 자식: {left_val}") print(f"오른쪽 자식: {right_val}") find_family(5) # 현재 노드: 50 # 부모 노드: 20 # 왼쪽 자식: 없음 # 오른쪽 자식: 없음
3 빈칸 채우기
리스트로 저장한 이진 탐색 트리(BST)에 값을 넣는 재귀 함수이다.
# bst 배열 초기화 (0은 빈 노드를 의미) bst = [0] * 30 # BST 데이터 삽입 함수 (재귀) def insert(idx, num): if 가: bst[idx] = num # 비어있는 노드이므로 데이터 저장 elif num < bst[idx]: 나 # 부모보다 작으면 왼쪽 서브트리로 else: 다 # 부모보다 크면 오른쪽 서브트리로 data = [10, 5, 15, 3, 7] for x in data: insert(1, x) print("생성된 BST 배열 일부:", bst[1:8]) # [10, 5, 15, 3, 7, 0, 0]
4 코드 작성
3번의 insert 함수를 작성하시오. 칸이 비어 있으면 값을 저장하고, 작으면 왼쪽 자식으로, 크거나 같으면 오른쪽 자식으로 재귀 호출한다.
bst = [0] * 30 def insert(idx, num): for x in [8, 3, 10, 1, 6]: insert(1, x) print(bst[1:8]) # [8, 3, 10, 1, 6, 0, 0]
5 빈칸 채우기
3번에서 만든 bst에서 값을 찾는 재귀 함수이다. 찾으면 True, 없으면 False를 반환한다.
# BST 데이터 탐색 함수 (재귀) def search(idx, num, cnt): if 가: print(f"{num}을(를) 찾을 수 없습니다. (비교 횟수: {cnt}회)") return False elif bst[idx] == num: print(f"{num}을(를) {cnt}번 비교 후 인덱스 {idx}에서 찾았습니다") return True elif num < bst[idx]: 나 # 왼쪽으로 이동 else: 다 # 오른쪽으로 이동 print(search(1, 7, 1)) # True print(search(1, 12, 1)) # False
6 코드 작성
4번에서 만든 bst에서 num을 찾는 재귀 함수 search(idx, num)를 작성하시오. 찾으면 True, 범위를 벗어나거나 빈 칸에 도달하면 False를 반환한다.

15 빈칸 채우기
13번의 graph를 큐로 BFS 하는 코드이다.
from collections import deque # BFS 구현 (큐 활용) def bfs(graph, start): visited = {node: False for node in graph} queue = 가 visited[start] = True result = [] while queue: v = 나 result.append(v) for neighbor in sorted(graph[v]): if not visited[neighbor]: 다 라 return result bfs_result = bfs(graph, 1) print(f"BFS 탐색 순서: {' -> '.join(map(str, bfs_result))}")

17 빈칸 채우기
친구 연결 상태가 인접 행렬로 주어진다. start에서 출발하여 target을 방문할 수 있으면 True, 방문할 수 없으면 False를 반환하는 함수를 DFS로 완성하시오.
# 0: A, 1: B, 2: C, 3: D, 4: E (E는 고립된 섬) graph_matrix = [ [0, 1, 1, 0, 0], # A-B, A-C [1, 0, 0, 1, 0], # B-A, B-D [1, 0, 0, 0, 0], # C-A [0, 1, 0, 0, 0], # D-B [0, 0, 0, 0, 0] # E (연결 안 됨) ] def is_connected(start, target): visited = [0] * len(graph_matrix) def dfs_check(cur): visited[cur] = 1 if 가: return True for next_node in range(len(graph_matrix)): if graph_matrix[cur][next_node] == 1 and 나: if 다: 라 return False return dfs_check(start) print("A와 D 연결 여부:", is_connected(0, 3)) # Expected: True print("A와 E 연결 여부:", is_connected(0, 4)) # Expected: False
18 빈칸 채우기
17번의 graph_matrix를 지하철역 연결망으로 보고, BFS로 출발역에서 목적지역까지 거쳐가는 최소 역의 개수(거리)를 구하는 함수를 완성하시오. 도달할 수 없으면 -1을 반환한다.
def min_distance(start, target): n = len(graph_matrix) distance = [-1] * n # 방문 안 함은 -1로 초기화 queue = [start] distance[start] = 0 # 자기 자신까지의 거리는 0 while queue: cur = 가 if cur == target: return 나 for next_node in range(n): if graph_matrix[cur][next_node] == 1 and 다: distance[next_node] = 라 마 return -1 # 연결되지 않은 경우 -> 즉 도달할 수 없는 경우 print("A(0번)에서 D(3번)까지 최단 거리:", min_distance(0, 3), "칸") # Expected: 2 (A->B->D) print("A(0번)에서 E(4번)까지 최단 거리:", min_distance(0, 4)) # Expected: -1
