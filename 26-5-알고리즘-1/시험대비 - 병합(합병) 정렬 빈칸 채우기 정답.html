시험대비 - 병합(합병) 정렬 빈칸 채우기 정답

밑줄 칸에 들어갈 코드를 쓴다. 밑줄 길이는 들어갈 코드의 글자 수와 같다. ...은 문제와 관계없어 내용을 생략한 부분이다.

1빈칸 채우기
다음은 리스트를 반으로 나누어 각각 정렬한 뒤 합치는 병합(합병) 정렬 코드이다. merge(L, R)은 정렬된 두 리스트 L, R을 합쳐 정렬된 리스트를 돌려주는 함수이며 내용은 생략했다. 빈칸 (가), (나)에 들어갈 코드를 쓰시오.
def merge_sort(A): if len(A) <= 1: return A m = len(A) // 2 L = 가merge_sort(A[:m]) R = 나merge_sort(A[m:]) return merge(L, R) def merge(L, R): ... print(merge_sort([5, 3, 8, 4, 2, 7, 1, 6]))

실행 결과

[1, 2, 3, 4, 5, 6, 7, 8]
(가)merge_sort(A[:m])(나)merge_sort(A[m:])

5빈칸 채우기
다음 병합(합병) 정렬 코드의 실행 결과가 아래와 같이 내림차순이 되도록 빈칸 (가)에 들어갈 조건을 쓰시오. merge_sort의 내용은 생략했다.

실행 결과

[8, 7, 6, 5, 4, 3, 2, 1]
(가)L[i] >= R[j]

L[i] > R[j]도 내림차순 정렬 결과는 같다. 같은 값이 있을 때 L 쪽을 먼저 꺼내는 것은 >= 이다.

7빈칸 채우기
다음은 리스트 A의 구간 lo ~ hi(양 끝 포함)를 새 리스트를 만들지 않고 제자리에서 정렬하는 병합(합병) 정렬 코드이다. merge(A, lo, mid, hi)는 정렬된 두 구간 lo ~ mid와 mid + 1 ~ hi를 합치는 함수이며 내용은 생략했다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
