1빈칸 채우기
리스트 members에는 동아리 회원의 (나이, 이름)이 가입한 순서대로 들어 있다. 다음 merge_sort(A)는 회원을 나이가 적은 순서대로 정렬해 새 리스트로 돌려주는 병합(합병) 정렬 함수이다. 나이가 같은 회원은 먼저 가입한 회원이 앞에 온다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def merge_sort(A): if len(A) <= 1: return A m = len(A) // 2 L = 가merge_sort(A[:m]) R = 나merge_sort(A[m:]) return merge(L, R) def merge(L, R): res = [] i = j = 0 while i < len(L) and j < len(R): if 다L[i][0] <= R[j][0]: res.append(L[i]) i += 1 else: res.append(R[j]) j += 1 return res + 라L[i:] + R[j:] members = [(21, '하준'), (21, '도윤'), (20, '서아'), (21, '가은'), (20, '민재')] print(merge_sort(members))

실행 결과

[(20, '서아'), (20, '민재'), (21, '하준'), (21, '도윤'), (21, '가은')]
(가)merge_sort(A[:m])(나)merge_sort(A[m:])(다)L[i][0] <= R[j][0](라)L[i:] + R[j:]

튜플의 0번 값(나이)만 비교하는 병합(합병) 정렬이다. 나이가 같을 때 왼쪽 리스트의 회원을 먼저 내보내야 가입 순서가 유지되므로 (다)는 <=이어야 한다. <로 쓰면 나이가 같을 때 오른쪽 회원이 먼저 나가 순서가 뒤바뀐다. L[i] <= R[j]로 쓰면 나이가 같을 때 이름까지 비교해 가나다순이 된다. (다)는 R[j][0] >= L[i][0]도 정답이다. (라)는 R[j:] + L[i:]도 정답이다. 비슷한 문제: 백준 10814 나이순 정렬.

2빈칸 채우기
다음 friend는 학생 1 ~ 7번의 친구 관계를 인접 리스트로 나타낸 것이다. 친구를 따라가서 닿을 수 있는 학생끼리는 같은 무리이다. 다음 dfs(v, visited)는 v번 학생에서 출발해 아직 들르지 않은 학생을 깊이 우선 탐색(DFS)으로 들르고, 들른 학생 수를 돌려주는 함수이다. 다음 groups()는 무리마다 학생 수를 구해 리스트로 돌려주는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
friend = { 1: [2, 5], 2: [1, 5], 3: [4], 4: [3, 6], 5: [1, 2], 6: [4], 7: [] } def dfs(v, visited): 가visited[v] = True size = 1 for nxt in friend[v]: if not visited[nxt]: 나size += dfs(nxt, visited) return size def groups(): visited = {v: False for v in friend} sizes = [] for v in friend: if 다not visited[v]: sizes.append(라dfs(v, visited)) return sizes print(groups(), len(groups()))

실행 결과

[3, 3, 1] 3
(가)visited[v] = True(나)size += dfs(nxt, visited)(다)not visited[v](라)dfs(v, visited)

연결 요소(무리)의 개수를 세는 DFS이다. 아직 들르지 않은 학생을 만날 때마다 dfs를 한 번 실행하면 그 학생의 무리 전체에 방문 표시가 된다. 그래서 dfs를 실행한 횟수가 무리의 수이다. (나)에서 재귀 호출이 돌려준 값을 size에 더하지 않으면 무리의 크기가 모두 1이 된다. (다)는 visited[v] == False도 정답이다. 비슷한 문제: 백준 11724 연결 요소의 개수.

3빈칸 채우기
리스트 bst는 이진 탐색 트리를 저장한 것이다. 루트는 1번 칸이고, idx번 칸의 왼쪽 자식은 idx * 2번 칸, 오른쪽 자식은 idx * 2 + 1번 칸이다. 0은 빈 칸이다. 다음 insert(num)은 num을 재귀 없이 반복으로 넣고, 루트에서 그 자리까지 내려간 횟수를 돌려주는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
bst = [0] * 64 def insert(num): idx = 1 depth = 0 while 가bst[idx] != 0: if num < bst[idx]: 나idx = idx * 2 else: 다idx = idx * 2 + 1 depth += 1 라bst[idx] = num return depth for x in [50, 30, 70, 20, 40, 60, 35]: print(insert(x), end=' ') print() print(bst[1:12])

실행 결과

0 1 1 2 2 2 3 [50, 30, 70, 20, 40, 60, 0, 0, 0, 35, 0]
(가)bst[idx] != 0(나)idx = idx * 2(다)idx = idx * 2 + 1(라)bst[idx] = num

이진 탐색 트리의 삽입을 반복으로 쓴 것이다. 빈 칸을 만날 때까지 작으면 왼쪽 자식, 그렇지 않으면 오른쪽 자식으로 내려간다. 35는 50, 30, 40과 차례로 비교해 40의 왼쪽 자식인 10번 칸에 들어가므로 내려간 횟수는 3이다. (가)는 bst[idx] > 0도 정답이다. (나)는 idx *= 2도 정답이다.

4빈칸 채우기
기둥 세 개 중 한 기둥에 크기가 서로 다른 원판 n개가 큰 것이 아래에 오도록 쌓여 있다. 원판은 한 번에 한 개씩 옮기고, 작은 원판 위에 큰 원판을 놓을 수 없다(하노이 탑). 다음 hanoi(n, a, b, c, moves)는 a 기둥의 원판 n개를 b 기둥을 거쳐 c 기둥으로 옮기는 과정을 (출발, 도착) 튜플로 moves에 차례로 넣는 함수이다. 위의 n - 1개를 b로 옮기고, 가장 큰 원판을 c로 옮긴 다음, b의 n - 1개를 c로 옮긴다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def hanoi(n, a, b, c, moves): if 가n == 0: return hanoi(n - 1, 나a, c, b, moves) 다moves.append((a, c)) hanoi(n - 1, 라b, a, c, moves) moves = [] hanoi(2, 'A', 'B', 'C', moves) print(moves) moves = [] hanoi(5, 'A', 'B', 'C', moves) print(len(moves))

실행 결과

(가)n == 0(나)a, c, b(다)moves.append((a, c))(라)b, a, c

하노이 탑의 점화식이다. 매개변수는 차례로 출발 기둥, 거치는 기둥, 도착 기둥이다. (나)는 a의 n - 1개를 c를 거쳐 b로 옮기는 호출이고, (라)는 b의 n - 1개를 a를 거쳐 c로 옮기는 호출이다. 옮기는 횟수는 T(n) = 2 × T(n - 1) + 1이어서 원판 5개는 31번이다. (가)는 n <= 0, n < 1도 정답이다. 비슷한 문제: 백준 11729 하노이 탑 이동 순서.

5빈칸 채우기
정수 n에 쓸 수 있는 연산은 세 가지이다. 1을 뺀다. 2로 나누어떨어지면 2로 나눈다. 3으로 나누어떨어지면 3으로 나눈다. 다음 make_one(n)은 n을 1로 만드는 데 필요한 연산 횟수의 최솟값을 상향식(표)으로 구하는 함수이다. d[i]는 i를 1로 만드는 최소 횟수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def make_one(n): d = [0] * (n + 1) for i in 가range(2, n + 1): d[i] = 나d[i - 1] + 1 if 다i % 2 == 0: d[i] = min(d[i], d[i // 2] + 1) if i % 3 == 0: d[i] = 라min(d[i], d[i // 3] + 1) return d[n] print(make_one(2), make_one(10), make_one(27))

실행 결과

1 3 3
(가)range(2, n + 1)(나)d[i - 1] + 1(다)i % 2 == 0(라)min(d[i], d[i // 3] + 1)

동적계획법 상향식(표)이다. i에서 한 번 연산한 결과는 i - 1, i // 2, i // 3 가운데 하나이므로, 세 값의 d 중 가장 작은 것에 1을 더한다. 10은 10 → 9 → 3 → 1의 3번이 최소이다. 나눌 수 있을 때 무조건 나누면 10 → 5 → 4 → 2 → 1의 4번이 되어 최소가 아니다. d[1]은 0이므로 (가)는 2부터 시작한다. 1부터 시작하면 d[1]이 d[0] + 1 = 1로 바뀐다. 비슷한 문제: 백준 1463 1로 만들기.
