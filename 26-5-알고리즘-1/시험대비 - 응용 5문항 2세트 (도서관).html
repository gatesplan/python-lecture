2빈칸 채우기
리스트 bst에는 책 번호가 이진 탐색 트리로 저장되어 있다. 루트는 1번 칸이고, idx번 칸의 왼쪽 자식은 idx * 2번 칸, 오른쪽 자식은 idx * 2 + 1번 칸이다. 0은 빈 칸이다. 다음 find(idx, num)은 번호가 num인 책이 들어 있는 칸의 번호를 돌려주고, 없으면 -1을 돌려주는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
bst = [0] * 16 for i, v in [(1, 500), (2, 300), (3, 800), (4, 100), (5, 400), (6, 700)]: bst[i] = v def find(idx, num): if idx >= len(bst) or 가: return -1 elif bst[idx] == num: return 나 elif num < bst[idx]: return find(다, num) else: return find(라, num) print(find(1, 400), find(1, 600))

실행 결과

5 -1
(가)(나)(다)(라)

[500, 300, 800, 100, 400, 700, 0]
