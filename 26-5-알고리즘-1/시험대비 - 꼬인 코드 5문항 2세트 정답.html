A = ...는 함수 안의 이름 A를 새 리스트로 옮길 뿐이어서 밖의 x는 그대로이다. A[:] = ...는 A가 가리키는 리스트의 내용을 통째로 바꾸므로 밖의 y도 정렬된다. sort1은 새 리스트를 돌려주므로 x와 다른 객체이고, sort2는 받은 리스트를 그대로 돌려주므로 y와 같은 객체이다.

(2, [1, 2, 2, 3, 0]) (3, [3, 2, 4, 1, 0]) (-1, [1, 2, 2, 3, 0]) (-1, [0, 0, 0, 0, 1])
visited가 방문 표시와 거리 기록을 겸한다. 0은 아직 들르지 않은 칸이고, 출발점을 1로 두었으므로 저장된 값은 거리 + 1이다. 그래서 끝에서 1을 뺀다. 닿을 수 없는 노드는 0으로 남아 0 - 1 = -1이 되어, 따로 검사하지 않아도 -1이 나온다. m[cur][nxt]가 1이면 참, not visited[nxt]는 0일 때 참이다.
3
[8, 3, 10, 3, 0, 9, 0, 0] [8, 3, 10, 3, 0, 9, 0, 1]
True는 1, False는 0으로 계산된다. num이 더 크면 idx * 2 + 1(오른쪽), 아니면 idx * 2(왼쪽)로 간다. 같은 값은 num > bst[idx]가 거짓이어서 왼쪽으로 간다. 둘째 3은 4번 칸에 들어간다. 0은 8번 칸에 들어가지만 0이 빈 칸 표시라 흔적이 없고, 다음에 넣은 1이 while bst[idx]를 그대로 통과해 같은 8번 칸에 들어간다.

3 1 1 0 -1
돌려주는 mid는 잘라 낸 리스트 안에서의 위치이다. 왼쪽으로 자르면 앞부분이 그대로라 위치가 맞지만, 오른쪽으로 자르면 앞의 mid + 1칸이 떨어져 나가 위치가 어긋난다. 11의 실제 위치는 5인데 [9, 11, 15]에서의 위치 1이 나오고, 15는 [15]에서의 위치 0이 나온다. 있는지 없는지는 맞게 판단한다.

(3, [1, 3, 4, 1]) (8, [1, 4, 8, 9, 1])
[[1] * k] * k는 행 리스트 하나를 k번 담는다. d[i]와 d[i - 1]이 같은 리스트이므로 d[i][j] = d[i - 1][j - 1] + d[i - 1][j]는 한 줄 안에서 row[j] = row[j - 1] + row[j]를 되풀이하는 셈이다. n이 4이면 그 한 줄이 [1, 2, 1, 1, 1], [1, 3, 4, 1, 1], [1, 4, 8, 9, 1]로 바뀐다. 3C1은 우연히 3으로 맞지만 4C2는 6이 아닌 8이 나온다.
