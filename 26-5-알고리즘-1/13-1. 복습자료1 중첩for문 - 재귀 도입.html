13-1. 중첩 for문에서 재귀까지

이중 for문으로 표의 칸을 골라 찍는다. 같은 방법으로 2개, 3개를 고르는 경우를 만든다. 마지막에 5개를 늘어놓는 코드를 5중 for문과 재귀 함수로 각각 쓴다.

표의 행 번호는 i, 열 번호는 j다. 칸 하나는 print(i, j, end='\t')로 찍는다.

1. 표의 칸 찍기 - 이중 for문

n = 4
for i in range(n):
    for j in range(n):
        print(i, j, end='\t')
    print()
출력
0 0	0 1	0 2	0 3	
1 0	1 1	1 2	1 3	
2 0	2 1	2 2	2 3	
3 0	3 1	3 2	3 3
  • 바깥 for의 i가 행 번호, 안쪽 for의 j가 열 번호다.
  • 안쪽 for가 한 번 끝나면 print()로 줄을 바꾼다. 찍힌 한 줄이 표의 한 행이다.

1-1. 하삼각 - j <= i

행 i에서 열 0부터 열 i까지 찍는다.

for i in range(n):
    for j in range(i + 1):
        print(i, j, end='\t')
    print()
출력 : 행마다 시작은 그대로, 한 칸씩 늦게 끝난다
0 0	
1 0	1 1	
2 0	2 1	2 2	
3 0	3 1	3 2	3 3

1-2. 상삼각 - j >= i

행 i에서 열 i부터 끝까지 찍는다. 그 앞의 열 0부터 열 i - 1까지는 빈 문자열과 탭을 찍어 자리를 맞춘다.

for i in range(n):
    for j in range(i):
        print('', end='\t')
    for j in range(i, n):
        print(i, j, end='\t')
    print()
출력 : 행마다 한 칸씩 늦게 시작하고, 끝은 그대로
0 0	0 1	0 2	0 3	
	1 1	1 2	1 3	
		2 2	2 3	
			3 3

빈칸을 찍는 for를 지우면 모든 줄이 왼쪽에 붙어 찍힌다.

1-3. 좌상삼각 - i + j <= n - 1

행 i에서 열 0부터 n - i개를 찍는다. 아래 행으로 갈수록 하나씩 줄어든다.

for i in range(n):
    for j in range(n - i):
        print(i, j, end='\t')
    print()
출력 : 행마다 시작은 그대로, 한 칸씩 빨리 끝난다
0 0	0 1	0 2	0 3	
1 0	1 1	1 2	
2 0	2 1	
3 0

1-4. 우하삼각 - i + j >= n - 1

행 i에서 열 n - 1 - i부터 끝까지 찍는다. 그 앞은 빈칸으로 채운다.

for i in range(n):
    for j in range(n - 1 - i):
        print('', end='\t')
    for j in range(n - 1 - i, n):
        print(i, j, end='\t')
    print()
출력 : 행마다 한 칸씩 빨리 시작하고, 끝은 그대로
			0 3	
		1 2	1 3	
	2 1	2 2	2 3	
3 0	3 1	3 2	3 3

네 코드 모두 바깥 for는 for i in range(n)로 같다. 안쪽 for의 범위만 다르고, 그 범위를 바깥 변수 i가 정한다.

2. 바깥 for와 안쪽 for 바꾸기

바깥 for를 열 번호 j, 안쪽 for를 행 번호 i로 쓴다.

for j in range(n):
    for i in range(n):
        print(i, j, end='\t')
    print()
출력
0 0	1 0	2 0	3 0	
0 1	1 1	2 1	3 1	
0 2	1 2	2 2	3 2	
0 3	1 3	2 3	3 3
  • 찍힌 한 줄이 표의 한 열이다.
  • 찍힌 모양은 1절 표의 행과 열을 바꾼 모양이다. 1절의 첫 줄은 0 0, 0 1, 0 2, 0 3, 여기의 첫 줄은 0 0, 1 0, 2 0, 3 0이다.

하삼각의 칸(j <= i)을 이 순서로 찍는다. 열 j에서 행 j부터 끝까지가 하삼각의 칸이다. 앞은 빈칸으로 채운다.

for j in range(n):
    for i in range(j):
        print('', end='\t')
    for i in range(j, n):
        print(i, j, end='\t')
    print()
출력 : 줄마다 한 칸씩 늦게 시작하고, 끝은 그대로
0 0	1 0	2 0	3 0	
	1 1	2 1	3 1	
		2 2	3 2	
			3 3

1-1과 같은 10칸을 찍는다. 찍는 순서가 열 단위로 바뀌어서, 찍힌 모양은 상삼각이다.

3. 2개 고르기 - 이중 for문

A = ['a', 'b', 'c', 'd']에서 2개를 골라 고른 순서대로 붙인다. i는 첫 번째로 고른 번호, j는 두 번째로 고른 번호다. 1절 표의 칸 (i, j) 하나가 A[i] + A[j] 하나다.

3-1. 중복순열 - 표 전체

같은 것을 또 고를 수 있고, 고른 순서가 다르면 다른 경우다.

n = len(A)
for i in range(n):

for i in range(n):

5. 5개 늘어놓기 - 5중 for문과 재귀 함수

A = ['a', 'b', 'c', 'd', 'e']의 5개를 한 번씩 모두 써서 늘어놓는 경우(5P5 = 120)를 만든다. 첫 번째 자리부터 다섯 번째 자리까지 차례로 하나씩 정한다.

5-1. 5중 for문

A = ['a', 'b', 'c', 'd', 'e']
n = len(A)

out1 = []
for i in range(n):
    for j in range(n):
        if j != i:
            for k in range(n):
                if k != i and k != j:
                    for l in range(n):
                        if l != i and l != j and l != k:
                            for m in range(n):
                                if m != i and m != j and m != k and m != l:
                                    out1.append(A[i] + A[j] + A[k] + A[l] + A[m])
print(len(out1))
print(out1[:8])
출력
120
['abcde', 'abced', 'abdce', 'abdec', 'abecd', 'abedc', 'acbde', 'acbed']

5-2. 재귀 함수

r = 5
out2 = []


def perm(path, s):            # path : 앞의 자리들에서 고른 번호, s : 고른 것을 붙인 문자열
    if len(path) == r:
        out2.append(s)
        return
    for i in range(n):
        if i not in path:
            perm(path + [i], s + A[i])

고르는 개수를 3으로 바꾼다. 5중 for문은 for 두 겹을 지우고 조건과 out1.append(...)를 고쳐 써야 한다. 재귀 함수는 r만 바꾼다.

확인할 것

  • 5중 for문의 i, j, k, l, m은 재귀 함수에서 어디에 들어 있는가.
  • 5중 for문에서 한 겹 들어갈 때마다 길어지는 조건은 재귀 함수의 어느 줄인가.
  • 5중 for문의 가장 안쪽 줄 out1.append(...)는 재귀 함수의 어느 줄인가.
  • 재귀 함수에서 perm이 한 번 불릴 때 for i in range(n)는 몇 번째 자리를 정하는가.

            for k in range(n):
                if k != j:
                    out.append(A[i] + A[j] + A[k])
print(len(out))
print(out[:9])

36개. k가 i와 같아도 걸러지지 않는다. 예: i = 0, j = 1, k = 0이면 aba가 나온다. (i, j)는 12가지, 그 각각에 k가 j만 피해 3가지라 12 x 3 = 36이다.

10. [코드 작성]

A = ['a', 'b', 'c']에서 3개를 고른다. 같은 것을 또 고를 수 있고 고른 순서는 따지지 않는다. 만들 수 있는 것을 리스트에 모아 개수와 함께 찍는 코드를 쓰시오.

정답
A = ['a', 'b', 'c']
n = len(A)
out = []
for i in range(n):
    for j in range(i, n):
        for k in range(j, n):
            out.append(A[i] + A[j] + A[k])
print(len(out))
print(out)
출력
10
['aaa', 'aab', 'aac', 'abb', 'abc', 'acc', 'bbb', 'bbc', 'bcc', 'ccc']

중복조합이다. 3H3 = 5C3 = 10
