4. 알고리즘 - 재귀 기초

함수/변수명은 알파벳 1~2글자로 난독화됨. 정답은 뒷장에 모아 정리.

1. 팩토리얼 (도입)

n! = n x (n-1) x ... x 1. 재귀로 보면 g(a) = a * g(a-1), 기저 조건은 g(1) = 1.

1-1 [출력 예측]
아래 코드의 출력을 먼저 예측한 뒤 실행한다.
def g(a): if a <= 1: return 1 return a * g(a-1) print(g(4)) # 예측: ? print(g(5)) # 예측: ?
1-2 [빈칸 - 기저 조건]
재귀를 멈추는 조건을 채워라.
def g(a): if ____: # 기저 조건 return 1 return a * g(a-1)
1-3 [디버깅 - 무한 재귀]
아래 함수는 무한 재귀에 빠진다. 한 곳을 고쳐라.
def g(a): if a == 1: return 1 return a * g(a)
1-4 [전체 작성]
a의 팩토리얼을 재귀로 구현하라. (g(6)=720, g(4)=24, g(1)=1)
def g(a): pass

2. 거듭제곱

b^e. 재귀 관계: b^e = b * b^(e-1), 기저 조건은 e == 0일 때 1.

2-1 [빈칸 - 재귀 호출]
return 부분을 채워라. (h(2,3)=8, h(3,4)=81)
def h(b, e): if e == 0: return 1 return ____
2-2 [트레이싱]
h(2, 4)를 실행하면 h는 총 몇 번 호출될까? (값은 16)
def h(b, e): if e == 0: return 1 return b * h(b, e-1) print(h(2, 4))

3. 배열 다루기 (합 / 최댓값)

배열도 '맨 뒤 원소 하나 + 나머지'로 쪼개면 재귀가 된다. n은 처리할 원소 개수.

3-1 [빈칸 - 배열 합]
a의 앞 n개 원소의 합. 빈칸을 채워라. (p([1,2,3,4],4)=10)
def p(a, n): if n == 0: return 0 return ____ + p(a, n-1)

앞 n개 원소의 최댓값을 재귀로 구하라. (p([3,1,4,1,5],5)=5)
def p(a, n): pass

4. 재귀 <-> 반복 변환

모든 재귀는 반복(for/while)으로 바꿀 수 있다. 팩토리얼을 for문으로 바꿔보자.

4-1 [블록 채우기]
for문 내부를 채워 팩토리얼을 완성하라. (q(5)=120, q(4)=24)
def q(n): r = 1 for i in range(1, n+1): pass # 여기를 채우세요 return r

5. 이중 재귀 (피보나치 / 계단 / 타일링)

한 번에 재귀를 두 번 부르는 형태: t(n) = t(n-1) + t(n-2). 피보나치, 계단 오르기, 2xn 타일링이 모두 같은 점화식이다.

5-1 [출력 예측]
피보나치. 출력을 먼저 예측하라.
def t(n): if n <= 1: return n return t(n-1) + t(n-2) print(t(6)) # 예측: ? print(t(7)) # 예측: ?
5-2 [빈칸 - 기저 조건]
두 기저 조건을 채워라. (t(5)=5, t(8)=21)
def t(n): if n == 0: return ____ if n == 1: return ____ return t(n-1) + t(n-2)
5-3 [응용 - 계단 오르기 / 타일링]
한 번에 1칸 또는 2칸 오를 때 n칸 계단을 오르는 방법의 수. (n=1이면 1, n=2이면 2) 재귀로 작성하라. 2xn 타일링도 같은 코드. (t(5)=8, t(6)=13)
def t(n): pass
5-4 [트레이싱 - 중복 호출]
위 피보나치로 t(5)를 실행하면 t가 총 몇 번 호출될까? 왜 이렇게 많은지 생각해보라.
c = 0 def t(n): global c c += 1 if n <= 1: return n return t(n-1) + t(n-2) t(5) print(c) # ?

6. 유클리드 호제법 (수학형 재귀)

두 수의 최대공약수(gcd). 핵심 성질: u(a, b) = u(b, a % b), 그리고 b == 0이면 u(a, 0) = a.

6-1 [빈칸 - 재귀 gcd]
기저 조건과 재귀 호출을 채워라. (u(24,36)=12, u(15,25)=5)
def u(a, b): if ____: return a return u(____, ____)
6-2 [트레이싱]
u(48, 18)을 계산할 때 (a, b)가 어떻게 바뀌는지 나열하고, 재귀가 몇 번 일어나는지 세어라.
def u(a, b): print("u(", a, ",", b, ")") if b == 0: return a return u(b, a % b) print("결과:", u(48, 18))

1. 팩토리얼 (도입)

1-1 [출력 예측]
출력: 24, 120
g(4) = 4*g(3) = 4*3*g(2) = 4*3*2*g(1) = 24 g(5) = 5*4*3*2*1 = 120
1-2 [빈칸 - 기저 조건]
a <= 1 (또는 a == 1)
def g(a): if a <= 1: return 1 return a * g(a-1)
1-3 [디버깅 - 무한 재귀]
g(a) -> g(a-1). a를 줄여야 기저 조건에 도달한다.
def g(a): if a == 1: return 1 return a * g(a-1)
1-4 [전체 작성]
def g(a): if a <= 1: return 1 return a * g(a-1)

2. 거듭제곱

2-1 [빈칸 - 재귀 호출]
b * h(b, e-1)
def h(b, e): if e == 0: return 1 return b * h(b, e-1)
2-2 [트레이싱]
5번. e가 4,3,2,1,0 으로 다섯 번 호출된다.
h(2,4) -> h(2,3) -> h(2,2) -> h(2,1) -> h(2,0)

3. 배열 다루기 (합 / 최댓값)

3-1 [빈칸 - 배열 합]
a[n-1] (현재 원소 + 나머지의 합)
def p(a, n): if n == 0: return 0 return a[n-1] + p(a, n-1)
3-2 [전체 작성 - 배열 최댓값]
def p(a, n): if n == 1: return a[0] return max(a[n-1], p(a, n-1))

def q(n): r = 1 for i in range(1, n+1): r = r * i return r

5. 이중 재귀 (피보나치 / 계단 / 타일링)

5-1 [출력 예측]
출력: 8, 13
피보나치: 0, 1, 1, 2, 3, 5, 8, 13, ... t(6)=8, t(7)=13
5-2 [빈칸 - 기저 조건]
0, 1
def t(n): if n == 0: return 0 if n == 1: return 1 return t(n-1) + t(n-2)
5-3 [응용 - 계단 오르기 / 타일링]
def t(n): if n == 1: return 1 if n == 2: return 2 return t(n-1) + t(n-2)
5-4 [트레이싱 - 중복 호출]
15번. t(3)을 2번, t(2)를 3번 중복 계산한다. 이중 재귀는 같은 값을 여러 번 다시 계산해서 n이 커지면 폭발적으로 느려진다.
t(5) / \ t(4) t(3) / \ / \ t(3) t(2) t(2) t(1)

6. 유클리드 호제법 (수학형 재귀)

6-1 [빈칸 - 재귀 gcd]
b == 0 / u(b, a % b)
def u(a, b): if b == 0: return a return u(b, a % b)
6-2 [트레이싱]
재귀 3번. b가 18, 12, 6, 0 으로 바뀌며 b == 0에서 멈춘다.
u(48, 18) -> u(18, 12) -> u(12, 6) -> u(6, 0) -> 결과 6
