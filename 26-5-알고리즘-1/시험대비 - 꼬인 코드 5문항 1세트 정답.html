i << 1은 i * 2, i >> 1은 i // 2이다. 슬라이스는 범위를 벗어나도 오류 없이 있는 만큼만 돌려주므로, C(3번)의 자식은 F 하나, D(4번)의 자식은 빈 리스트가 된다. 루트의 부모 자리는 tree[0]이라 0이 나온다. 마지막 줄에서 <<는 |보다 먼저, +는 <<보다 먼저 계산된다. 3 << 1 | 1은 (3 << 1) | 1 = 7이고 1 << 2 + 1은 1 << 3 = 8이다.

a, b = b, a % b는 오른쪽 두 값을 먼저 모두 계산한 다음 한꺼번에 넣는다. gcd2는 a = b를 먼저 하므로 다음 줄의 a % b는 b % b, 곧 0이 된다. 그래서 한 바퀴 만에 끝나고 처음의 b가 그대로 나온다. while b는 b가 0이 아닌 동안 돈다.

기본 인자 memo={}는 함수를 정의할 때 한 번만 만들어지고 호출 사이에 계속 남는다. 첫 호출이 memo에 1, 2, 3, 5(1 ~ 4칸)를 남겨서, 둘째 호출은 걸음이 [1, 3]으로 바뀌었는데도 저장된 5를 그대로 돌려준다. 셋째는 memo[4] + memo[2] = 5 + 2 = 7이다. 넷째는 빈 딕셔너리를 넘겼지만 재귀 호출에는 넘기지 않아서, 안쪽은 여전히 남아 있는 memo를 쓴다. memo[3] + memo[1] = 3 + 1 = 4이다. 걸음이 [1, 3]일 때 옳은 값은 4칸 3가지, 5칸 4가지이다.
