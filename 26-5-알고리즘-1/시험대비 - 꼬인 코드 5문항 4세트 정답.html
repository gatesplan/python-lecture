큐에 넣을 때가 아니라 꺼낼 때 방문 표시를 한다. 2를 꺼냈을 때 4는 아직 visited에 없어 큐에 들어가고, 3을 꺼냈을 때도 4가 visited에 없어 한 번 더 들어간다. 4가 두 번 꺼내지고, 그때마다 5를 넣어서 5도 두 번 나온다. 넣을 때 visited에 적으면 중복이 생기지 않는다.

[1, b][e % 2]는 e가 짝수이면 1, 홀수이면 b를 고른다. 지수를 반으로 줄였지만 같은 호출을 두 번 하므로 호출 횟수는 T(e) = 2 × T(e // 2) + 1이다. T(0) = 1, T(1) = 3, T(2) = 7, T(4) = 15이므로 T(5) = 15, T(8) = 31이다. 값을 한 번만 구해 변수에 두고 두 번 곱하면 e가 8일 때 5번이면 된다.

d[-1]은 맨 뒤 칸, d[-2]는 뒤에서 둘째 칸이다. 맨 뒤에 1을 붙여 두면 i가 0일 때 d[-1] + d[-2] = 1 + 0 = 1, i가 1일 때 d[0] + d[-1] = 1 + 1 = 2가 되어 시작값을 따로 넣지 않아도 1, 2, 3, 5, 8이 채워진다. 맨 뒤의 1은 답이 아니라 시작값 자리이다. n이 1이면 d[-2]가 d[0] 자신이고 아직 0이다.
