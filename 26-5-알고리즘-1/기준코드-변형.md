# 기준 코드 변형
`기준코드.md`의 기준 코드마다 같은 알고리즘의 자연스러운 다른 버전을 모았다. 번호 n-k는 기준 코드 n의 k번째 변형이다(기준 코드가 둘이면 nA-k, nB-k).
변형 종류: 내림차순, 비교 조건, 반복과 재귀, 그 밖에 같은 구현의 흔한 다른 형태. 이름 바꾸기와 함수 쪼개기는 하지 않았다.
모든 코드는 실행했다. 정렬 변형은 무작위 리스트 300여 개로 결과를 확인했다.

#### 1A-1. 내림차순

merge의 비교를 `>=`로 바꿨다.

```python
def merge_sort(A):
    if len(A) <= 1:
        return A

    m = len(A) // 2
    L = merge_sort(A[:m])
    R = merge_sort(A[m:])

    return merge(L, R)


def merge(L, R):
    res = []
    i = j = 0
    while i < len(L) and j < len(R):
        if L[i] >= R[j]:
            res.append(L[i])
            i += 1
        else:
            res.append(R[j])
            j += 1
    res.extend(L[i:])
    res.extend(R[j:])
    return res


print(merge_sort([5, 3, 8, 4, 2, 7, 1, 6]))
```

#### 1A-4. pop(0)으로 앞에서 꺼내기

인덱스 i, j 대신 두 리스트의 맨 앞 값을 비교해 `pop(0)`으로 꺼낸다.

```python
def merge_sort(A):
    if len(A) <= 1:
        return A

    m = len(A) // 2
    L = merge_sort(A[:m])
    R = merge_sort(A[m:])

    return merge(L, R)


def merge(L, R):
    res = []
    while len(L) > 0 and len(R) > 0:
        if L[0] <= R[0]:
            res.append(L.pop(0))
        else:
            res.append(R.pop(0))
    return res + L + R


print(merge_sort([5, 3, 8, 4, 2, 7, 1, 6]))
```

#### 1A-5. 반복 (아래에서 위로)

```python
def merge_sort(A):
    width = 1
    while width < len(A):
        res = []

            R = A[lo + width:lo + 2 * width]
            res.extend(merge(L, R))
        A = res
        width *= 2
    return A
```

#### 1B-4. 반복 (아래에서 위로)

재귀 없이 길이 width인 이웃 구간 두 개씩 merge한다. width가 1, 2, 4, ...로 두 배씩 커진다. merge는 기준 코드와 같다.

```python
def merge_sort(A):
    n = len(A)
    width = 1
    while width < n:
        for lo in range(0, n, 2 * width):
            mid = min(lo + width - 1, n - 1)
            hi = min(lo + 2 * width - 1, n - 1)
            if mid < hi:
                merge(A, lo, mid, hi)
        width *= 2
```

### 2A. 퀵 정렬 - 양쪽 커서

#### 2A-1. 내림차순

두 커서의 비교 방향을 바꿨다. 왼쪽 커서는 피벗보다 큰 값을 지나가고, 오른쪽 커서는 작은 값을 지나간다.

```python
def partition(A, lo, hi):
    p = A[hi]
    i = lo
    j = hi - 1

    while True:
        while i <= j and A[i] > p:
            i += 1
        while i <= j and A[j] < p:
            j -= 1

        if i >= j:
            break

        A[i], A[j] = A[j], A[i]
        i += 1
        j -= 1

    A[i], A[hi] = A[hi], A[i]
    return i


def quick_sort(A, lo, hi):
    if lo >= hi:
        return

    m = partition(A, lo, hi)
    quick_sort(A, lo, m - 1)
    quick_sort(A, m + 1, hi)


A = [5, 3, 8, 4, 2, 7, 1, 6]
quick_sort(A, 0, len(A) - 1)
print(A)
```

실행 결과:

```
[8, 7, 6, 5, 4, 3, 2, 1]
```

#### 2A-3. 반복 (스택에 구간 쌓기)

재귀 호출 대신 남은 구간 `(lo, hi)`를 스택에 넣고 하나씩 꺼내 분할한다.

```python
def partition(A, lo, hi):
    p = A[hi]
    i = lo
    j = hi - 1

    while True:
        while i <= j and A[i] < p:
            i += 1
        while i <= j and A[j] > p:
            j -= 1

        if i >= j:
            break

        A[i], A[j] = A[j], A[i]
        i += 1
        j -= 1

    A[i], A[hi] = A[hi], A[i]
    return i


def quick_sort(A):
    stack = [(0, len(A) - 1)]
    while len(stack) > 0:
        lo, hi = stack.pop()
        if lo >= hi:
            continue

        m = partition(A, lo, hi)
        stack.append((lo, m - 1))
        stack.append((m + 1, hi))

print(A)
```

#### 6-1. DFS를 반복으로 (스택)

재귀 대신 스택을 쓴다. 작은 번호부터 방문하도록 이웃을 큰 번호부터 넣는다. 꺼낼 때 방문 표시를 한다.

```python
graph = {
    1: [2, 3, 4],
    2: [1, 5, 6],
    3: [1],
    4: [1],
    5: [2, 7],
    6: [2],
    7: [5]
}

def dfs(graph, start):
    visited = {node: False for node in graph}
    stack = [start]
    result = []

    while len(stack) > 0:
        v = stack.pop()
        if visited[v]:
            continue
        visited[v] = True
        result.append(v)
        for neighbor in sorted(graph[v], reverse=True):
            if not visited[neighbor]:
                stack.append(neighbor)
    return result


print(dfs(graph, 1))
```

```python
from collections import deque

def min_distance(start, target):
    n = len(graph_matrix)
    distance = [-1] * n

    queue = deque([start])
    distance[start] = 0

    while queue:
        cur = queue.popleft()
        if cur == target:
            return distance[cur]
        for next_node in range(n):
            if graph_matrix[cur][next_node] == 1 and distance[next_node] == -1:
```

```python
def comb_table(n, r):
```
