1빈칸 채우기
아이스크림 가게에 계산대가 두 개 있다. 각 계산대에는 주문 번호가 작은 순서대로 쌓여 있다. 다음 merge(L, R)은 두 계산대의 주문 번호를 번호가 작은 순서대로 한 줄로 합쳐 돌려주는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.

(가)i < len(L) and j < len(R)(나)L[i] <= R[j](다)L[i:](라)R[j:]

병합(합병) 정렬의 merge이다. (나)는 L[i] < R[j]도 정답이다. (다)와 (라)는 서로 바꿔 써도 정답이다. while이 끝나면 둘 중 하나는 빈 리스트이기 때문이다.

2빈칸 채우기
메뉴판에는 아이스크림 가격이 싼 것부터 적혀 있다. 다음 find(prices, target)은 가격이 target인 메뉴의 위치를 이진 탐색으로 찾아, 위치와 가격을 비교한 횟수 cnt를 함께 돌려주는 함수이다. 그 가격의 메뉴가 없으면 위치는 -1이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.

(5, 2) (-1, 3)
(가)low <= high(나)low = mid + 1(다)high = mid - 1

반복으로 쓴 이진 탐색이다. (가)는 high >= low도 정답이다. (나)를 low = mid, (다)를 high = mid로 쓰면 구간이 줄지 않는 경우가 생겨 끝나지 않는다.

3빈칸 채우기
다음 town은 동네 지도를 인접 리스트로 나타낸 것이다. 배달원은 한 번에 이웃한 장소로 한 칸 이동한다. 다음 min_moves(start, goal)은 start에서 goal까지 가는 데 필요한 최소 이동 횟수를 너비 우선 탐색(BFS)으로 구하는 함수이다. dist에는 각 장소까지의 이동 횟수를 저장하고, 갈 수 없으면 -1을 돌려준다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.

실행 결과

3 -1
(가)queue.popleft()(나)nxt not in dist(다)dist[cur] + 1

BFS로 구하는 최단 칸 수이다. dist에 들어 있는 장소는 이미 방문한 장소이므로 dist가 방문 기록 역할도 한다. (가)를 queue.pop()으로 쓰면 스택처럼 꺼내게 되어 최소 이동 횟수가 보장되지 않는다.

4빈칸 채우기
컵에 아이스크림을 n스쿱 담는다. 한 번에 1스쿱, 2스쿱 또는 3스쿱을 담을 수 있고, 담는 순서가 다르면 다른 방법이다. 다음 scoops(n)은 n스쿱을 담는 방법의 수를 상향식(표)으로 구하는 함수이다. d[i]는 i스쿱을 담는 방법의 수이고 n은 3 이상이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def scoops(n): d = [0] * (n + 1) d[1] = 1 d[2] = 가2 d[3] = 나4 for i in range(4, n + 1): d[i] = 다d[i - 1] + d[i - 2] + d[i - 3] return d[n] print(scoops(4), scoops(6))

실행 결과

7 24
(가)2(나)4(다)d[i - 1] + d[i - 2] + d[i - 3]

계단 오르기와 같은 구조의 점화식이다. 마지막에 1스쿱, 2스쿱, 3스쿱을 담는 경우로 나누면 d[i] = d[i - 1] + d[i - 2] + d[i - 3]이다. 2스쿱은 1+1, 2의 2가지, 3스쿱은 1+1+1, 1+2, 2+1, 3의 4가지이다. (다)는 더하는 순서를 바꿔 써도 정답이다.
