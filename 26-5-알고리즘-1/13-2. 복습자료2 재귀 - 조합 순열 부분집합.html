4. 합 들고 다니기

A2 = [0, 1, 2, 7, 9, 10, 15, 16]
best = -1


def comb_sum(d, prev, s):      # 1절의 comb와 같은 모양. s가 합이다
    global best                # best에 새 값을 대입하므로 global이 필요하다
    if d == 3:
        if s % 3 == 0:         # 합이 3의 배수일 때만
            best = max(best, s)
        return
    for i in range(prev + 1, len(A2)):
        comb_sum(d + 1, i, s + A2[i])

  • 원소 B[k]를 넣지 않는 호출 sub_sum(k + 1, s)를 먼저, 넣는 호출 sub_sum(k + 1, s + B[k])를 나중에 한다.
  • 모든 원소를 정한 호출(k == m)은 16개다. 그중 합이 10인 것만 찍는다.
  • B[0] = 2를 넣지 않는 쪽을 먼저 끝까지 돌기 때문에 [3, 7]이 [2, 3, 5]보다 먼저 찍힌다.
