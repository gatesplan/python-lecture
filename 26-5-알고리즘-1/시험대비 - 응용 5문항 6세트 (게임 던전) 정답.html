1빈칸 채우기
다음 dungeon은 던전의 방 1 ~ 6번과 방 사이의 문을 인접 리스트로 나타낸 것이다. 다음 explore(start)는 start번 방에서 가까운 방부터 차례로 들르는 너비 우선 탐색(BFS) 함수이고, 들른 순서를 리스트로 돌려준다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
from collections import deque dungeon = { 1: [2, 3], 2: [1, 4, 5], 3: [1, 6], 4: [2], 5: [2, 6], 6: [3, 5] } def explore(start): visited = {room: False for room in dungeon} queue = deque([start]) 가visited[start] = True result = [] while queue: v = queue.popleft() result.append(v) for nxt in dungeon[v]: if 나not visited[nxt]: 다visited[nxt] = True 라queue.append(nxt) return result print(explore(1), explore(5))

실행 결과

[1, 2, 3, 4, 5, 6] [5, 2, 6, 1, 4, 3]
(가)visited[start] = True(나)not visited[nxt](다)visited[nxt] = True(라)queue.append(nxt)

인접 리스트의 BFS(큐)이다. (나)는 visited[nxt] == False도 정답이다. (다)와 (라)는 서로 바꿔 써도 정답이다.

2빈칸 채우기
리스트 S에는 플레이어들의 점수가 들어 있다. 다음 rank_sort(S)는 점수가 높은 것부터 놓이도록 정렬하는 삽입 정렬 함수이다. i번째 점수 k를 앞부분의 알맞은 자리에 끼워 넣는다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def rank_sort(S): for i in range(1, len(S)): k = S[i] j = i - 1 while j >= 0 and 가S[j] < k: S[j + 1] = S[j] 나j -= 1 다S[j + 1] = k S = [320, 510, 150, 480, 700] rank_sort(S) print(S)

실행 결과

[700, 510, 480, 320, 150]
(가)S[j] < k(나)j -= 1(다)S[j + 1] = k

내림차순 삽입 정렬이다. 오름차순에서는 k보다 큰 값을 뒤로 밀지만, 여기서는 k보다 작은 값을 뒤로 민다. (가)는 k > S[j]도 정답이다. (나)는 j = j - 1도 정답이다.

3빈칸 채우기
리스트 skill은 스킬 트리를 이진 트리로 저장한 것이다. 루트는 1번 칸이고, idx번 칸의 부모는 idx // 2번 칸이다. 어떤 스킬을 배우려면 그 스킬의 부모 스킬을 먼저 배워야 한다. 다음 need(idx)는 idx번 칸의 스킬부터 루트까지 거슬러 올라가며 만나는 스킬을 차례로 리스트에 담아 돌려주는 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
skill = [0, '기본기', '검술', '마법', '베기', '찌르기', '불', '얼음'] def need(idx): path = [] while 가idx >= 1: path.append(나skill[idx]) idx = 다idx // 2 return path print(need(5)) print(need(7)) print(need(1))

실행 결과

['찌르기', '검술', '기본기'] ['얼음', '마법', '기본기'] ['기본기']
(가)idx >= 1(나)skill[idx](다)idx // 2

리스트로 저장한 이진 트리에서 부모의 위치는 idx // 2이다. 루트(1번)의 부모 위치는 0이 되어 반복이 끝난다. (가)는 idx > 0, idx != 0도 정답이다.

4빈칸 채우기
던전의 계단을 한 번에 1칸 또는 3칸씩 오른다. 다음 climb(n)은 n칸을 오르는 방법의 수를 구하는 함수이다. 한 번 구한 값은 딕셔너리 memo에 저장해 두고 다시 쓴다(메모이제이션). 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
memo = {} def climb(n): if n < 3: return 1 if 가n in memo: return 나memo[n] memo[n] = 다climb(n - 1) + climb(n - 3) return memo[n] print(climb(3), climb(5), climb(40))

실행 결과

2 4 2670964
(가)n in memo(나)memo[n](다)climb(n - 1) + climb(n - 3)

마지막에 1칸을 오르는 경우와 3칸을 오르는 경우로 나누면 climb(n) = climb(n - 1) + climb(n - 3)이다. n이 3보다 작으면 1칸씩 오르는 방법 1가지뿐이다. 5칸은 1+1+1+1+1, 1+1+3, 1+3+1, 3+1+1의 4가지이다. (다)는 더하는 순서를 바꿔 써도 정답이다.

5빈칸 채우기
무기를 한 번 강화할 때마다 공격력이 base배가 된다. 공격력 1인 무기를 exp번 강화하면 공격력은 base의 exp제곱이다. 다음 attack(base, exp)는 지수를 절반으로 줄여 재귀 호출하는 방법으로 이 값을 구하는 함수이다. 지수가 절반인 값을 한 번만 구해 half에 두고 쓴다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def attack(base, exp): if exp == 0: return 가1 half = 나attack(base, exp // 2) if exp % 2 == 0: return 다half * half else: return 라half * half * base print(attack(2, 10), attack(3, 5), attack(5, 0))

실행 결과

1024 243 1
(가)1(나)attack(base, exp // 2)(다)half * half(라)half * half * base

지수를 반으로 줄이는 거듭제곱(분할정복)이다. exp가 홀수이면 exp // 2가 내림되므로 base를 한 번 더 곱한다. (다)는 half ** 2도 정답이다. (라)는 곱하는 순서를 바꿔 써도 정답이다.
