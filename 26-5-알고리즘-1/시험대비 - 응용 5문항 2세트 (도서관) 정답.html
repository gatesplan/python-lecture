1빈칸 채우기
도서관 서가 shelf에는 책 번호가 작은 순서대로 꽂혀 있다. 다음 put_back(shelf, book)은 반납된 책 book을 서가의 맨 뒤에 놓은 다음, book보다 번호가 큰 책을 뒤로 한 칸씩 밀고 알맞은 자리에 꽂는 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def put_back(shelf, book): shelf.append(book) j = len(shelf) - 2 while 가j >= 0 and shelf[j] > book: 나shelf[j + 1] = shelf[j] j -= 1 다shelf[j + 1] = book shelf = [110, 230, 340, 410, 580] put_back(shelf, 300) print(shelf) put_back(shelf, 50) print(shelf)

실행 결과

[110, 230, 300, 340, 410, 580] [50, 110, 230, 300, 340, 410, 580]
(가)j >= 0 and shelf[j] > book(나)shelf[j + 1] = shelf[j](다)shelf[j + 1] = book

삽입 정렬에서 값 하나를 끼워 넣는 부분이다. (가)는 j > -1 and shelf[j] > book도 정답이다. (가)에서 j >= 0을 빼면 book이 가장 작을 때 j가 -1이 되어 shelf[-1], 곧 맨 뒤 값과 비교하게 된다.

2빈칸 채우기
리스트 bst에는 책 번호가 이진 탐색 트리로 저장되어 있다. 루트는 1번 칸이고, idx번 칸의 왼쪽 자식은 idx * 2번 칸, 오른쪽 자식은 idx * 2 + 1번 칸이다. 0은 빈 칸이다. 다음 find(idx, num)은 번호가 num인 책이 들어 있는 칸의 번호를 돌려주고, 없으면 -1을 돌려주는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
bst = [0] * 16 for i, v in [(1, 500), (2, 300), (3, 800), (4, 100), (5, 400), (6, 700)]: bst[i] = v def find(idx, num): if idx >= len(bst) or 가bst[idx] == 0: return -1 elif bst[idx] == num: return 나idx elif num < bst[idx]: return find(다idx * 2, num) else: return find(라idx * 2 + 1, num) print(find(1, 400), find(1, 600))

실행 결과

5 -1
(가)bst[idx] == 0(나)idx(다)idx * 2(라)idx * 2 + 1

이진 탐색 트리의 탐색이다. (다)는 2 * idx, (라)는 2 * idx + 1도 정답이다. 600은 500, 800, 700과 차례로 비교한 뒤 빈 칸(12번)에 도착해 -1이 된다.

3빈칸 채우기
다음 register(idx, num)은 새로 들어온 책의 번호 num을 이진 탐색 트리 bst에 넣는 함수이다. 루트는 1번 칸이고 0은 빈 칸이다. 지금 칸의 번호보다 작으면 왼쪽 자식으로, 그렇지 않으면 오른쪽 자식으로 내려간다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
bst = [0] * 16 def register(idx, num): if 가bst[idx] == 0: 나bst[idx] = num elif 다num < bst[idx]: register(idx * 2, num) else: register(idx * 2 + 1, num) for x in [500, 300, 800, 100, 400, 700]: register(1, x) print(bst[1:8])

실행 결과

[500, 300, 800, 100, 400, 700, 0]
(가)bst[idx] == 0(나)bst[idx] = num(다)num < bst[idx]

이진 탐색 트리의 삽입이다. (다)는 bst[idx] > num도 정답이다. 실행 결과는 앞 문제의 트리와 같다.

4빈칸 채우기
다음 hall은 도서관의 방과 방 사이 통로를 인접 리스트로 나타낸 것이다. 다음 can_go(cur, goal, visited)는 cur에서 통로를 따라 goal까지 갈 수 있으면 True, 없으면 False를 돌려주는 깊이 우선 탐색(DFS) 함수이다. visited는 이미 들른 방의 리스트이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
hall = { '입구': ['열람실', '어린이실'], '열람실': ['입구', '서고'], '어린이실': ['입구'], '서고': ['열람실'], '보존실': ['수리실'], '수리실': ['보존실'] } def can_go(cur, goal, visited): visited.append(cur) if cur == goal: return True for nxt in hall[cur]: if 가nxt not in visited: if 나can_go(nxt, goal, visited): return 다True return 라False print(can_go('입구', '서고', [])) print(can_go('입구', '수리실', []))

실행 결과

True False
(가)nxt not in visited(나)can_go(nxt, goal, visited)(다)True(라)False

DFS로 확인하는 연결 여부이다. 학교 코드는 visited를 0과 1의 리스트로 두지만 여기서는 들른 방의 이름을 모은 리스트로 두었다. (나)에서 재귀 호출의 결과가 True일 때만 True를 돌려준다. return can_go(nxt, goal, visited)로 쓰면 첫 이웃에서 못 찾았을 때 다른 이웃을 보지 않고 끝난다.

5빈칸 채우기
추천 도서 n권 중에서 r권을 골라 전시한다. 다음 pick(n, r)은 고르는 방법의 수(nCr)를 구하는 함수이다. 한 번 구한 값은 (n, r) 튜플을 키로 하는 딕셔너리 memo에 저장해 두고 다시 쓴다(메모이제이션). 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
memo = {} def pick(n, r): if 가r == 0 or r == n: return 1 if 나(n, r) in memo: return 다memo[(n, r)] memo[(n, r)] = 라pick(n - 1, r - 1) + pick(n - 1, r) return memo[(n, r)] print(pick(5, 2), pick(30, 15))

실행 결과

10 155117520
(가)r == 0 or r == n(나)(n, r) in memo(다)memo[(n, r)](라)pick(n - 1, r - 1) + pick(n - 1, r)

조합의 점화식 nCr = (n-1)C(r-1) + (n-1)Cr에 메모이제이션을 붙인 것이다. (가)는 r == n or r == 0도 정답이다. (라)는 두 호출의 순서를 바꿔 써도 정답이다.
