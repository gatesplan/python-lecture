1빈칸 채우기
매점에서 거스름돈 money원을 동전으로 거슬러 준다. 리스트 coins에는 동전의 금액이 큰 것부터 들어 있다. 다음 change(money, coins)는 큰 동전부터 줄 수 있는 만큼 주는 방법(탐욕)으로 거슬러 줄 때 동전의 개수를 돌려주는 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.

실행 결과

6 7
(가)money // c(나)money %= c(다)count

탐욕 알고리즘이다. (가)는 c원 동전을 줄 수 있는 개수이고, (나)는 그만큼 주고 남은 금액이다. (나)는 money = money % c도 정답이다. 1260원은 500원 2개, 100원 2개, 50원 1개, 10원 1개로 6개이다.

2빈칸 채우기
매점 앞에 선 학생들을 키가 작은 순서대로 다시 세운다. 다음 line_up(H)는 이웃한 두 학생을 비교해 앞 학생이 더 크면 자리를 바꾸는 버블 정렬 함수이다. 한 바퀴 동안 자리를 한 번도 바꾸지 않았으면 반복을 끝내고, 돈 바퀴 수 rounds를 돌려준다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.

실행 결과

2 [158, 162, 165, 171, 175]
(가)n - i - 1(나)H[j] > H[j + 1](다)swapped = True(라)break

교환이 없으면 멈추는 버블 정렬이다. (가)는 n - 1 - i도 정답이다. (나)는 H[j + 1] < H[j]도 정답이다. 첫 바퀴에서 171과 165를 바꾸고, 둘째 바퀴에서는 바꾼 것이 없어 멈추므로 rounds는 2이다.

3빈칸 채우기
리스트 price에 들어 있는 과자 가격을 퀵 정렬로 싼 것부터 정렬한다. partition(A, lo, hi)는 마지막 값을 기준으로 구간 lo ~ hi를 나누는 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def partition(A, lo, hi): p = A[hi] i = lo for j in range(lo, hi): if A[j] < p: A[i], A[j] = A[j], A[i] i += 1 A[i], A[hi] = A[hi], A[i] return 가i def quick_sort(A, lo, hi): if 나lo >= hi: return m = partition(A, lo, hi) quick_sort(A, 다lo, m - 1) quick_sort(A, 라m + 1, hi) price = [1200, 800, 1500, 500, 1000, 700] quick_sort(price, 0, len(price) - 1) print(price)

실행 결과

[500, 700, 800, 1000, 1200, 1500]
(가)i(나)lo >= hi(다)lo, m - 1(라)m + 1, hi

퀵 정렬(한쪽 커서)이다. partition이 돌려주는 값은 기준 값이 놓인 위치이고, 이 자리는 확정되었으므로 재귀 호출 구간에서 뺀다. (나)는 hi <= lo도 정답이다. (다)와 (라)는 서로 바꿔 써도 정답이다.

4빈칸 채우기
매점의 과자 n종류 중에서 r종류를 골라 세트로 판다. 다음 snack_set(n, r)은 고르는 방법의 수(nCr)를 상향식(표)으로 구하는 함수이다. d[i][j]는 i종류 중 j종류를 고르는 방법의 수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.

실행 결과

10 120
(가)j == 0 or j == i(나)d[i - 1][j - 1] + d[i - 1][j](다)d[n][r]

조합의 점화식을 표로 채운 것이다. (가)는 j == i or j == 0도 정답이다. (나)는 두 항의 순서를 바꿔 써도 정답이다.
