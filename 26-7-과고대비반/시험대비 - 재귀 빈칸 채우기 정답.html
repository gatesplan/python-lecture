시험대비 - 재귀 빈칸 채우기 정답

밑줄 칸에 들어갈 코드를 쓴다. 밑줄 길이는 들어갈 코드의 글자 수와 같다.

1빈칸 채우기
다음 factorial(n)은 n!을 돌려주는 재귀 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def factorial(n): if 가n <= 1: return 나1 return 다n * factorial(n - 1) print(factorial(5))

실행 결과

120
(가)n <= 1(나)1(다)n * factorial(n - 1)

(가)는 n == 1, n < 2, n == 0도 정답이다. (다)는 factorial(n - 1) * n도 정답이다.

2빈칸 채우기
다음 power(base, exp)는 base의 exp제곱을 돌려주는 재귀 함수이다. 빈칸 (가), (나)에 들어갈 코드를 쓰시오.
def power(base, exp): if 가exp == 0: return 1 return 나base * power(base, exp - 1) print(power(2, 10), power(3, 0))

실행 결과

1024 1
(가)exp == 0(나)base * power(base, exp - 1)

(나)는 power(base, exp - 1) * base도 정답이다.

3빈칸 채우기
다음 list_sum(arr, n)은 arr의 앞에서부터 n개 값의 합을 돌려주는 재귀 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def list_sum(arr, n): if n == 0: return 가0 return 나arr[n - 1] + list_sum(arr, 다n - 1) print(list_sum([1, 2, 3, 4], 4)) print(list_sum([1, 2, 3, 4], 2))

실행 결과

10 3
(가)0(나)arr[n - 1](다)n - 1
4빈칸 채우기
다음 list_sum(arr, i)는 arr의 인덱스 i부터 끝까지 값의 합을 돌려주는 재귀 함수이다. 맨 앞 값과 나머지의 합을 더한다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def list_sum(arr, i): if 가i == len(arr): return 0 return 나arr[i] + list_sum(arr, 다i + 1) print(list_sum([1, 2, 3, 4], 0)) print(list_sum([1, 2, 3, 4], 2))

실행 결과

10 7
(가)i == len(arr)(나)arr[i](다)i + 1

(가)는 i >= len(arr)도 정답이다.

5빈칸 채우기
다음 list_max(arr, n)은 arr의 앞에서부터 n개 값 중 최댓값을 돌려주는 재귀 함수이다. 앞의 n - 1개 중 최댓값 m을 먼저 구하고, n번째 값과 비교한다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def list_max(arr, n): if n == 1: return 가arr[0] m = 나list_max(arr, n - 1) if 다arr[n - 1] > m: return arr[n - 1] else: return m print(list_max([3, 1, 4, 1, 5], 5)) print(list_max([3, 1, 4, 1, 5], 2))

실행 결과

5 3
(가)arr[0](나)list_max(arr, n - 1)(다)arr[n - 1] > m

(다)는 arr[n - 1] >= m, m < arr[n - 1]도 정답이다.

6빈칸 채우기
다음 fib(n)은 피보나치 수열의 n번째 값을 돌려주는 재귀 함수이다. fib(0) = 0이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def fib(n): if n == 0: return 0 if 가n == 1: return 나1 return 다fib(n - 1) + fib(n - 2) print(fib(8))

실행 결과

21
(가)n == 1(나)1(다)fib(n - 1) + fib(n - 2)

(가)는 n <= 1, n < 2도 정답이다. (다)는 fib(n - 2) + fib(n - 1)도 정답이다.

7빈칸 채우기
계단을 한 번에 1칸 또는 2칸씩 오른다. 다음 stairs(n)은 n칸을 오르는 방법의 수를 돌려주는 재귀 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def stairs(n): if n == 1: return 가1 if n == 2: return 나2 return 다stairs(n - 1) + stairs(n - 2) print(stairs(5))

실행 결과

8
(가)1(나)2(다)stairs(n - 1) + stairs(n - 2)

(다)는 stairs(n - 2) + stairs(n - 1)도 정답이다.

8빈칸 채우기
다음 comb(n, r)은 서로 다른 n개에서 r개를 고르는 방법의 수(nCr)를 돌려주는 재귀 함수이다. 빈칸 (가), (나), (다)에 들어갈 코드를 쓰시오.
def comb(n, r): if 가r == 0 or r == n: return 1 return 나comb(n - 1, r - 1) + 다comb(n - 1, r) print(comb(5, 2))

실행 결과

10
(가)r == 0 or r == n(나)comb(n - 1, r - 1)(다)comb(n - 1, r)

(나)와 (다)는 서로 바꿔 써도 정답이다. (가)는 r == n or r == 0도 정답이다.

9빈칸 채우기
다음 gcd(a, b)는 유클리드 호제법으로 a와 b의 최대공약수를 돌려주는 재귀 함수이다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def gcd(a, b): if 가b == 0: return 나a return gcd(다b, 라a % b) print(gcd(24, 36))

12
(가)b == 0(나)a(다)b(라)a % b
10빈칸 채우기
다음 power(base, exp)는 지수를 절반으로 줄여 재귀 호출하는 거듭제곱 함수이다. 지수가 절반인 거듭제곱을 한 번만 구해 half에 두고, half를 두 번 곱해 쓴다. 빈칸 (가) ~ (라)에 들어갈 코드를 쓰시오.
def power(base, exp): if exp == 0: return 1 half = 가power(base, exp // 2) if 나exp % 2 == 0: return 다half * half else: return 라half * half * base print(power(2, 10), power(2, 5), power(3, 0))

실행 결과

1024 32 1
(가)power(base, exp // 2)(나)exp % 2 == 0(다)half * half(라)half * half * base

(나)는 exp % 2 != 1도 정답이다. (다)는 half ** 2도 정답이다. (라)는 곱하는 순서를 바꿔 써도 정답이다.
